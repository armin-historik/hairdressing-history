# International Hairdressing History Project

Independent archival research initiative exploring the history of hairdressing, its pioneers, technologies, industries and international networks.

Public website: https://hairdressing-history.org/

## Deployment

Static HTML and CSS hosted on GitHub Pages. Enable Pages in repository **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.

The `CNAME` file declares the custom domain. Configure the registrar's DNS for GitHub Pages separately and enable HTTPS once GitHub verifies DNS.

## Research scope

Approximately 1880–1950, including relevant earlier and later developments. Separate thematic collections may be published later. Related independent projects are distinguished from the hairdressing-history initiative.
