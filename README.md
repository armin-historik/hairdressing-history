# International Hairdressing History Project

Museum-style development homepage for GitHub Pages.

## Deployment
Upload index.html, style.css and assets/ to the repository root. GitHub Pages: main / (root). No CNAME file until the domain is registered.

## Important
The illustrative image crops are derived from an AI-generated design mockup and are NOT authentic archival photographs. Replace with sourced historical photographs before presenting them as documentary material. The HTML currently uses `noindex,follow` while the site is in development; remove this meta tag before requesting Google indexing.
